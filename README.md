# Harshit Chaudhary — Portfolio

Personal portfolio built with React and Vite. It presents Harshit's software engineering experience, aerial robotics work, projects, education, and contact information.

## Live website

[harshitc-27.github.io/portfolio](https://harshitc-27.github.io/portfolio/)

## Local development

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
```

Pushes to the `main` branch are automatically deployed through GitHub Actions.
